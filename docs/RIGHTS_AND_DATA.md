# Data attribution and package rights

South German Credit [Dataset] (2020), UCI Machine Learning Repository.
DOI: https://doi.org/10.24432/C5QG88
Landing page: https://archive.ics.uci.edu/dataset/573/south+german+credit
Data license: Creative Commons Attribution 4.0 International.
License terms: https://creativecommons.org/licenses/by/4.0/
Retrieved 2026-10-09.

The original ASCII file, R documentation and code table are bundled unchanged.
The canonical CSV translates German field names to the documented English names
and changes the binary target to bad_credit=1-kredit. All rows and row order are
preserved. The underlying amount is a transformed historical amount, not a modern
validated monetary EAD estimate. Source and package file hashes are included.

The supplied manuscript remains the authors' work. No license is newly assigned
to the manuscript or code on the authors' behalf. Public distribution of the
manuscript/code should use a license selected by its rights holders. The UCI data
license is independent of that choice. Third-party libraries keep their own licenses.

No live customer data, credentials, administrative extracts or analyst evaluations
are bundled. The package uses the public historical benchmark only.
